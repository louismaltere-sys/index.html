## C'est quoi AMFPrep ? 🤔

AMFPrep est une **application web complète de révision pour la certification AMF** (Autorité des Marchés Financiers). Elle fonctionne directement dans votre navigateur — pas d'installation, pas de compte à créer, pas d'internet requis une fois téléchargée.

Elle couvre l'intégralité du programme officiel de l'examen AMF généraliste.

---

## Ce que contient la plateforme 📚

### 200 questions réparties sur 10 modules

| Module | Thèmes couverts |
|---|---|
| 📊 Instruments Financiers | Actions, obligations, ETF, OPCVM, crypto-actifs, dérivés, produits structurés |
| ⚖️ Réglementation | MiFID II, MAR, AMF, ACPR, ESMA, BCE, Bâle III, SFDR, UCITS |
| 🛡️ Conformité | RCCI, contrôle interne, cartographie des risques, FATCA, CRS, DORA |
| 🎯 Déontologie | Délit d'initié, manipulation de cours, front running, churning, PDMR |
| 🏛️ Gestion Collective | OPCVM, SICAV, FCP, hedge funds, dépositaire, ALM, ratio de Sharpe |
| 📈 Produits Dérivés | Options, futures, swaps, grecques, EMIR, compensation centrale |
| 🏦 Marchés Financiers | Euronext, MTF, OTF, post-marché, Euroclear, IPO, OPA, HFT |
| 🌱 ESG & Finance Durable | SFDR, taxonomie UE, CSRD, TCFD, green bonds, label ISR, EU ETS |
| 🔍 LCB-FT | KYC, TRACFIN, blanchiment, PPE, gel des avoirs, GAFI, AMLA |
| 🤝 Relation Client | Catégorisation MiFID II, test adéquation, démarchage, FGDR, DICI |

### Fonctionnalités

- **Mode entraînement** — correction immédiate après chaque réponse + explication détaillée
- **Mode examen** — conditions réelles, timer, correction à la fin
- **Examen blanc** — 40 questions en 60 minutes, seuil de réussite à 75 %
- **Correction intelligente** — quand vous vous trompez, la bonne réponse s'affiche en vert avec une explication
- **Suivi de progression** — score par module, historique, heatmap d'activité
- **Statistiques** — radar chart, évolution des scores, tableau de performance
- **Gamification** — système XP, 20 niveaux (Novice → Grand Master), 10 badges à débloquer
- **100 % hors ligne** — fonctionne sans internet une fois le fichier téléchargé

## Comment télécharger et utiliser 📥

### Étape 1 — Télécharger le fichier

1. En haut de cette page GitHub, cliquez sur le fichier **`amfprep.html`**

   ![Cliquer sur le fichier](https://i.imgur.com/placeholder.png)

2. Une fois sur la page du fichier, cliquez sur le bouton **⬇️ Download raw file** (l'icône de téléchargement en haut à droite)

3. Le fichier `amfprep.html` se télécharge sur votre ordinateur (généralement dans le dossier **Téléchargements**)

---

### Étape 2 — Ouvrir le fichier

1. Allez dans votre dossier **Téléchargements**
2. Double-cliquez sur `amfprep.html`
3. Le site s'ouvre automatiquement dans votre navigateur (Chrome, Firefox, Safari, Edge — tous compatibles)

> ✅ C'est tout ! Aucune installation, aucun compte requis.

---

### Étape 3 — Commencer à réviser

- Cliquez sur **"Modules"** pour choisir un thème spécifique
- Cliquez sur **"Commencer à réviser"** pour un quiz rapide
- Cliquez sur **"Examen Blanc"** pour simuler les conditions réelles de l'examen

---

### 💡 Conseil important — Toujours utiliser le même fichier

Votre progression (score, XP, badges, historique) est **sauvegardée automatiquement dans votre navigateur**. Pour ne pas perdre votre progression :

- ✅ Utilisez toujours le **même navigateur** sur le **même ordinateur**
- ✅ Ne supprimez pas l'historique/les données de votre navigateur
- ❌ Si vous ouvrez le fichier sur un autre navigateur ou un autre appareil, la progression repart à zéro
